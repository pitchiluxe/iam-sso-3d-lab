# Lab 01 — Enterprise IAM Foundation

## Real-world scenario
You are joining an IT/IAM team responsible for a 150-user company. You must establish the identity foundation used by the help desk, security, and application teams.

## Objectives
- Build an AD domain.
- Configure DNS.
- Create organizational units (OUs).
- Create users, groups, and service accounts.
- Establish naming conventions.
- Apply baseline Group Policy.
- Demonstrate least privilege.

## 3D environment
The learner walks through:
- IT operations room
- Domain Controller room
- Help Desk
- HR office
- Finance office
- Security operations area
- Application server room

Interactive objects:
Domain Controller, workstation, identity dashboard, user directory, ticket console, policy console.

## Workflow
1. Install Windows Server.
2. Configure a static IP and DNS.
3. Promote the server to a domain controller.
4. Create fictional departments.
5. Create OUs for Users, Groups, Computers, Servers, Service Accounts.
6. Create security groups based on job functions.
7. Create test users.
8. Join a Windows client to the domain.
9. Apply baseline policies.
10. Test authentication.
11. Record changes in the IAM change log.

## Evidence
- Domain works.
- Test user can authenticate.
- User receives the correct group memberships.
- Client is domain joined.
- Policies apply successfully.

## Interview skills demonstrated
Directory administration, RBAC concepts, troubleshooting, documentation, change management.
