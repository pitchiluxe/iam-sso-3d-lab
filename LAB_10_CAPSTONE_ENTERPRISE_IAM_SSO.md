# Lab 10 — Enterprise IAM + SSO Capstone

## Scenario
You are the IAM engineer for a fictional 500-user company. HR, IT, Security, Finance, and Engineering use several business applications.

## Mission
Build and operate the identity environment from onboarding through termination while providing SSO and secure access.

## Required components
- Active Directory
- DNS
- Windows clients
- Linux service
- Identity provider
- SAML application
- OIDC application
- MFA
- RBAC
- Help desk workflow
- Audit/access review process
- Security incident workflow

## Capstone workflow
1. Build the directory.
2. Create organizational structure.
3. Configure users and groups.
4. Implement RBAC.
5. Onboard five fictional employees.
6. Move two employees between departments.
7. Terminate one employee.
8. Integrate two applications with SSO.
9. Enforce MFA for privileged users.
10. Conduct an access review.
11. Investigate an SSO outage.
12. Investigate a suspicious login.
13. Produce an audit report.
14. Present the architecture and troubleshooting decisions as if interviewing for an IAM/SSO position.

## Final deliverables
- Architecture diagram
- IAM procedure
- SSO configuration record
- Access matrix
- Joiner/Mover/Leaver records
- Incident report
- Access-review report
- Change log
- Final troubleshooting runbook

## Job-readiness standard
You should be able to explain:
- Authentication vs authorization
- IAM lifecycle
- RBAC and least privilege
- SSO
- SAML vs OIDC
- MFA
- Directory services
- Identity provider
- Claims/attributes
- Session/token concepts
- Access reviews
- Privileged access
- Identity incident response
- How you troubleshoot an SSO outage
