How to use the lab
(and how the AI instructor intervenes).

A five-step walkthrough: install Ollama, enter a scenario, open the consoles, ask the AI supervisor for help, and read the four-level hint ladder when you're stuck.

Table of contents

Each step takes two to three minutes.

Before you start

The lab works without Ollama — the in-app hint ladder still nudges you in the right direction. But to talk to the AI Supervisor you need Ollama running locally.

1

Install Ollama & pull the model

~ 2 minutes

1. Download Ollama for your platform from ollama.com and install it like any other app. Ollama runs in the background and listens on http://localhost:11434.

2. Pull the model the lab expects. Open a terminal:

ollama pull llama3.2

The first pull downloads a few gigabytes. After that, Ollama starts instantly. The lab talks to it on every step — no further config needed.

What the lab uses: default base URL http://localhost:11434, default model llama3.2. Override at runtime with window.env.OLLAMA_BASE_URL and window.env.OLLAMA_MODEL. Set window.env.OLLAMA_DISABLED = "true" to force local-only mode (no network calls).

3. The lab auto-detects Ollama on launch. The status dot in the AI Supervisor console turns green when it's online.

Enter the lab

Pick a scenario, walk in, open a console.

2

Pick a scenario & walk the campus

~ 1 minute

1. Launch the app. The start screen lists all scenarios as cards. Click one to enter.

2. You're now in a first-person 3D view of the enterprise campus. Move with WASD or the arrow keys; look with the mouse. Open the in-game briefing panel (press Tab) to read the objectives for the current step.

3. Walk to any of the consoles marked in the world. Each opens an overlay with its own UI:

  • IAM Console — provision users, create groups, manage group membership, enable MFA.
  • Ticket Console — read incoming tickets, triage, resolve, escalate.
  • SecOps Dashboard — alerts, audit log, session revocation, fault indicators.
  • AI Supervisor — chat with the local Ollama model. This is where the AI instructor lives.

4. Complete each step's objectives in order. The conductor watches your audit log; when a step's validators pass, it advances automatically.

Tip: You can reset a lab at any time from the start screen. Reset wipes the audit log, the score, and the evidence collected so far.

AI Supervisor console

The AI instructor lives in its own console. Open it any time to ask a question, score your current step, or request a hint.

3

Three ways to use the console:

  • 📊 Score my step — sends the last 20 audit events to Ollama and returns a six-category breakdown (exec, troubleshoot, least-privilege, docs, evidence, comms) plus a coaching note.
  • 🧭 Where am I stuck? — asks Ollama for a Socratic nudge based on the current step's hint ladder.
  • Free-text input — ask anything about the current step. The supervisor will not give you the answer; it will ask you the next question.
If Ollama is offline: the console shows "Ollama offline — using local hint" and falls back to the built-in hint ladder. Your progress is not blocked — the lab still scores your steps, just without AI coaching.

How the AI instructor intervenes

The instructor never gives you the answer. It reveals progressively stronger hints, one rung at a time, until you find the path yourself.

4

The four-level hint ladder

Real example · Lab 01, Step 1

Every step has a hint ladder — four messages, ordered from a gentle steer to the actual answer. The instructor picks the right level based on how stuck you are. You can also ask for each level directly from the AI Supervisor console.

1nudge
Names the territory, not the action.
"Identities are how the directory knows who a person is. What three things does a directory need to know about every person?"
2question
A diagnostic question that steers your reasoning.
"If you had to introduce a new employee to the system, what fields would you fill in?"
3approach
Names the action and where to look, but not the values.
"Use the IAM Console 'Provision User' form. Username, display name, and email are the minimum."
4solution
The actual answer — reserved for explanation mode.
"Open the IAM Console, fill in username/display/email/dept/title, click 'Create User'."
Why four levels? Because an interview doesn't ask you to read the manual — it asks you to defend the path you took. The hint ladder trains that defense. The earlier you find the answer, the more it counts.

Troubleshooting

If something doesn't respond, walk down this list.

5

Common issues & fixes

~ 2 minutes

"AI Supervisor offline" in the console. Ollama isn't running, or it's listening on a non-default port. Start it with ollama serve, then click Check status in the console header. If you changed the port, set window.env.OLLAMA_BASE_URL before launching.

"Model not found" error. The supervisor expects llama3.2. Pull it: ollama pull llama3.2. To use a different model, set window.env.OLLAMA_MODEL (e.g. mistral, phi3).

"No active lab" in the console. The AI supervisor only responds during an active scenario. Return to the start screen and pick a lab card.

Supervisor is responding but never converges. Small local models (under 7B parameters) can drift off-format. Either upgrade to llama3.2 or larger, or set window.env.OLLAMA_DISABLED = "true" to fall back to the deterministic local scorer.

3D scene won't load / black canvas. Your GPU may have WebGL disabled, or the Electron build is running on an unsupported driver. Use the browser build as a fallback — it serves the same lab from npm run dev.

Score isn't updating. The conductor scores each step on advance, not on save. Complete all the step's validators (visible in the briefing panel), then the conductor will record your score and move to the next step.
